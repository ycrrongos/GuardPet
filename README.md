# 守伴

陪伴守护形桌宠。工程从 `MIKU-仅参考` 独立复制而来，应用名「守伴」，包名 `com.geekathon.guardpet`。

## 本版能力

- 悬浮窗桌宠：拖拽、行走、心情/饥饿、到点睡觉
- 单击打开菜单：提取文字、闪记、番茄钟、控制小窗
- 番茄钟 / 应用与网站拦截：接入开源 [Reef](https://github.com/aload0/Reef)（MIT，设置页保留署名，不得使用 Reef 名称与图标）
- 提取文字：无障碍读取当前界面，按字/词点选后复制、搜索或送进闪记
- 闪记：右侧胶囊悬浮窗。手势可分别打开列表或开始记录（录音/手动）；卡片可换色，主页日记同步色点；语音卡可重放/暂停/继续
- 夜间作息守护：规则引擎根据用量、今日日程和习惯，禁用无关应用，或锁机催睡，或只放行相关应用

## 运行

1. 用 Android Studio 打开本目录 `GuardPet`
2. JDK 17、Android SDK 37、AGP 9.2、Gradle 9.5
3. 真机 Android 8.0+ 安装运行
4. 开启桌宠时允许「显示在其他应用上层」
5. 番茄钟 / 提取文字 / 夜间拦截需要用量访问和无障碍「守伴守护」
6. 语音闪记需要麦克风权限

专注功能基于 Reef。衍生使用必须在设置或关于页保留指向原仓库的链接。
